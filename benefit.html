⚖ Perbedaan Fundamental: Pola Teks vs Realisasi Penghematan Nyata

Keberhasilan mereproduksi 100.00% teks narasi Benefit membuktikan integritas formula linguistik. Namun pemangku kepentingan (*stakeholders*) tidak boleh menyamakan kalimat narasi dengan penghematan waktu aktual yang sudah terjadi di lingkungan produksi:

Fully Automated (389 Baris) Realisasi 100%

Otomasi crontab/dashboard sudah aktif di produksi. Penghematan durasi operasional bersifat aktual dan riil setiap bulannya menggantikan jam kerja manual staf L1.

Not Yet Triggered (256 Baris) Realisasi Potensial

Script/tool otomasi sudah selesai dibangun, namun eksekusinya bersifat reaktif (menunggu insiden terjadi) atau belum dikaitkan ke event webhook otomatis. Penghematan bersifat potensial.

Partial Automated (22 Baris) Realisasi Sebagian

Solusi otomatis telah membantu sebagian alur kerja tiket, tetapi eksekusi atau verifikasi akhir masih memerlukan inisiasi manual manusia (*human-in-the-loop*). Penghematan hanya tereduksi sebagian.

Bagian 2

Benefit Generation Logic: Alur Sintesis Deterministik

Visualisasi terstruktur bagaimana setiap slot kalimat Benefit dirakit secara berjenjang dari 6 atribut operasional.

1. Input Angka
Mengambil atribut Durasi (Menit) dan Event Per Month, kemudian menghitung beban waktu bulanan: Workload = Durasi × Event.
2. Format Waktu
RULE-BEN-01: Jika Workload < 60 → "{W} minutes".
Jika Workload ≥ 60 → konversi jam H = W / 60.0. Jika bulat gunakan int(H) + " hours", jika pecahan gunakan format(H, ".1f") + " hours".
3. Klausul Event
RULE-BEN-02: Jika Event == 1 → "(saving {Durasi} minutes per event)".
Jika Event > 1 → "(saving {Durasi} minutes per event across {Event} monthly events)".
4. Preposisi Tool
RULE-BEN-03: Standar → "via {Tools Automation}".
Pengecualian: CICD → "via CI/CD automation"; Not Automate → "through standardized automation".
5. Frasa Aksi Baku
Memetakan Category Action ke salah satu dari 6 frasa semantik kanonikal (contoh: Smart Healing → "automated fault detection and self-healing recovery").
6. Penggabungan Slot
RULE-BEN-04: Menggabungkan seluruh komponen ke dalam template eksekutif sesuai Status Triggered: {Prefix Verb} + {Workload Str} + {Scope Clause} + {Duration Clause} + {Tool Clause} + through + {Action Phrase} + "."

Katalog Kasus Khusus (Special Cases & Exceptions)

Dua anomali struktural terisolasi yang ditemukan pada rekonsiliasi dataset REA: Workload = 0 dan Anomali Preposisi Ganda.

RULE-BEN-05 • EXC-04 2 Kasus Terisolasi

Kasus Khusus 1: Workload Bernilai Nol (Workload = 0)

Jika aktivitas memiliki durasi 0 menit di dataset mentah, formula waktu reguler tidak dapat mencetak "0 minutes". Sistem tata bahasa beralih ke template kualitatif khusus percepatan pemulihan:

Template Baku Workload 0: "{Prefix} manual intervention time and accelerates system recovery {once_automated} {tool_clause} through {action_phrase}."

EXC-05 2 Kasus Terisolasi

Kasus Khusus 2: Pengecualian Preposisi Ganda ("through ... through")

Ketika Tools Automation == 'Not Automate', frasa perkakas menghasilkan "through standardized automation". Saat disambungkan dengan klausul aksi baku yang juga diawali kata "through", tercipta repetisi preposisi ganda:

Pola Terbentuk di Benchmark: ... through standardized automation through {action_phrase}.
